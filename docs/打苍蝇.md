## 一、剧情与玩法流程（完善版）

### 场景设定
- **舞台**：左右分屏式构图。左边站着「人」（喝饮料），右边或中央是「兔子」。
- **开局**：一群普通苍蝇 + 少量金苍蝇在天空乱飞，人皱眉、不耐烦（循环动画 + 头顶气泡「烦死了」）。
- **转折**：兔子变身「兔子小孩」——变身动画（白光/星星特效），小孩跳下地面，拿起苍蝇拍。
- **主玩法**：兔子小孩满地图打苍蝇，玩家点击/触摸苍蝇。
- **失败条件**：打空 10 次 → 小孩坐地上哭（哭动画 + 眼泪粒子）。
- **兜底剧情**：人把手里的饮料当手雷扔出去 → 抛物线飞行动画 → 爆炸特效 → 全屏苍蝇清空。
- **结局**：人抱起小孩 → 幕布从上/两侧落下 → 结算分数。

### 分数规则
| 事件 | 分数 |
|---|---|
| 普通苍蝇 | +10 |
| 金色苍蝇 | +50 |
| 连击（连续命中不空挥） | 每 5 连 +额外 20 |
| 打空 | 0 分，打空计数 +1 |
| 打中金苍蝇失败 | 弹出「打不着打不着」文字 |

### 关键状态机
```
IDLE(开场) → FLYING(苍蝇飞+人烦躁)
   → TRANSFORM(兔子变身)
   → PLAYING(打苍蝇主循环)
       ├─ 打空计数 = 10 → FAIL_CRY(小孩哭)
       └─ 清空所有苍蝇 → WIN_BOMB(扔饮料)
   → BOMB(手雷爆炸清场)
   → HUG(人抱小孩) → CURTAIN(幕布) → RESULT(结算)
```

> 注意：你的设定里「打空 10 次」触发的是**兜底扔手雷**，而不是直接 Game Over。所以它其实是「失败但用剧情救场」，最终仍然进结算。建议明确：**打空 10 次 = 触发结局动画，不再继续打**，这样剧情闭环。

## 二、技术选型

| 方案 | 适合度 | 说明 |
|---|---|---|
| **原生 HTML + Canvas 2D + JS** | ⭐⭐⭐⭐⭐ 推荐 | 无依赖、轻量、动画和点击判定都好做，适合这种 2D 动画小游戏 |
| Phaser 3 | ⭐⭐⭐⭐ | 有场景/精灵/动画/物理，做起来更快，但要多学一套 API |
| PixiJS | ⭐⭐⭐⭐ | 渲染性能强，适合大量精灵，但逻辑要自己写 |
| React + Canvas | ⭐⭐⭐ | 可以，但游戏循环别用 React state 驱动 |
| Cocos / Unity | ⭐⭐ | 对这么小的游戏过重 |

**推荐：原生 Canvas 2D 单文件起步**，后续要扩展再考虑 Phaser。
理由：你的核心是「精灵动画 + 点击判定 + 时间轴剧情」，Canvas 完全够，且你项目里如果是 Web 前端可直接嵌入。

**配套技术**
- 动画：`requestAnimationFrame` + 逐帧 sprite 或序列帧
- 音效：Web Audio API / `<audio>` 池化
- 文字弹出「打不着打不着」：DOM 覆盖层或 Canvas 文字 + 缓动
- 特效：粒子系统（爆浆、眼泪、爆炸）
- 本地存档：`localStorage` 存最高分

## 四、分步实现方案

### 第 0 步：搭骨架

`<canvas>` 全屏，`requestAnimationFrame` 主循环，`dt` 帧率无关。

### 第 1 步：苍蝇系统（先做这个，最好玩）
- `Fly` 类：位置、速度、类型、半径、抖动相位
- 从屏幕边缘随机生成
- 正弦抖动飞行，边界反弹/逃逸
- 渲染：普通灰、金色带闪光
- 金苍蝇随机「闪现」：每隔 1~2 秒瞬移到附近位置

### 第 2 步：点击判定
- `pointerdown` 监听
- 圆形碰撞检测（半径 +6px 手感放宽）
- 命中普通 → +10、爆浆粒子、音效
- 命中金色 → +50、金色粒子
- 点空 → 打空计数 +1、空挥音效
- **金苍蝇没打中**：在点击位置弹出「打不着打不着」，1 秒后消失

### 第 3 步：角色与剧情状态机
按上面的状态机实现，用 `state.status` 切换：
- `IDLE`：人喝饮料循环，苍蝇开始飞
- `TRANSFORM`：兔子白光变身（1.5 秒）
- `PLAYING`：小孩出现，玩家可点击
- `FAIL_CRY`：打空满 10 次 → 小孩坐下哭
- `BOMB`：人扔饮料 → 抛物线 → 爆炸 → 清空所有苍蝇
- `HUG`：人抱小孩
- `CURTAIN`：幕布落下（CSS/Canvas 动画 1 秒）
- `RESULT`：结算面板

每个状态有 `enter()` / `update(dt)` / `exit()`，用时间轴控制动画帧。

### 第 4 步：难度与平衡
- 随时间提升生成频率、速度、金苍蝇概率
- 打空计数显示为 10 个爱心，空一次灭一个
- 连击系统：连续命中不空挥，5 连加成分

### 第 5 步：特效与反馈
- 命中：屏幕轻微震动 + 粒子 + 音效
- 打空：屏幕闪红一下 + 「咻」
- 金苍蝇闪现：残影 + 「叮」
- 爆炸：全屏白闪 + 粒子 + 震动

### 第 6 步：结算与重玩
- 显示：总分、命中数、打空数、最高分（localStorage）
- 「再来一局」按钮重置所有状态

### 第 7 步：适配与打磨
- 移动端：`touch-action: none`，DPR 缩放防模糊，命中半径放大
- 性能：对象池复用苍蝇和粒子，粒子上限 300
- 音效池化，避免频繁 new Audio

```js
// 状态机
const GameState = {
  IDLE: 'idle', TRANSFORM: 'transform', PLAYING: 'playing',
  FAIL_CRY: 'failCry', BOMB: 'bomb', HUG: 'hug',
  CURTAIN: 'curtain', RESULT: 'result'
};

const game = {
  status: GameState.IDLE,
  score: 0,
  missCount: 0,
  combo: 0,
  flies: [],
  particles: [],
  timer: 0,          // 当前状态计时
  difficulty: 0,
  setState(s) { this.status = s; this.timer = 0; this.onEnter(s); },
  onEnter(s) {
    if (s === GameState.TRANSFORM) this.timer = 0;
    if (s === GameState.BOMB) { /* 播放扔饮料动画 */ }
    if (s === GameState.RESULT) saveHighScore(this.score);
  }
};

// 主循环
let last = performance.now();
function loop(now) {
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  game.timer += dt;

  switch (game.status) {
    case GameState.IDLE:
      updateFlies(dt);          // 苍蝇先飞起来
      if (game.timer > 3) game.setState(GameState.TRANSFORM);
      break;
    case GameState.TRANSFORM:
      if (game.timer > 1.5) game.setState(GameState.PLAYING);
      break;
    case GameState.PLAYING:
      game.difficulty += dt * 0.1;
      updateFlies(dt);
      maybeSpawn(dt);
      break;
    case GameState.FAIL_CRY:
      if (game.timer > 2) game.setState(GameState.BOMB);
      break;
    case GameState.BOMB:
      updateBomb(dt);           // 抛物线 + 爆炸
      if (game.timer > 2.5) game.setState(GameState.HUG);
      break;
    case GameState.HUG:
      if (game.timer > 2) game.setState(GameState.CURTAIN);
      break;
    case GameState.CURTAIN:
      if (game.timer > 1.2) game.setState(GameState.RESULT);
      break;
  }
  updateParticles(dt);
  render();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

// 点击
canvas.addEventListener('pointerdown', e => {
  if (game.status !== GameState.PLAYING) return;
  const { x, y } = toCanvasCoord(e);
  for (let i = game.flies.length - 1; i >= 0; i--) {
    const f = game.flies[i];
    const dx = x - f.x, dy = y - f.y;
    if (dx*dx + dy*dy <= (f.radius + 6) ** 2) {
      if (f.type === 'gold') { game.score += 50; }
      else { game.score += 10; }
      game.combo++;
      spawnSplat(f.x, f.y, f.type === 'gold' ? '#ffd700' : '#333');
      game.flies.splice(i, 1);
      return;
    }
  }
  // 打空
  onMiss(x, y);
});

function onMiss(x, y) {
  game.missCount++;
  game.combo = 0;
  // 如果点空的位置附近有金苍蝇，弹「打不着打不着」
  const goldNear = game.flies.some(f =>
    f.type === 'gold' && (f.x - x) ** 2 + (f.y - y) ** 2 < 120 ** 2
  );
  if (goldNear) showText('打不着打不着', x, y);
  if (game.missCount >= 10) game.setState(GameState.FAIL_CRY);
}
```

```html
// ============ 苍蝇 ============
const FLY_TYPES = {
  normal: { score: 10, radius: 26, speed: 90,  color: '#3a3a3a', emoji: '🪰' },
  gold:   { score: 50, radius: 22, speed: 150, color: '#ffd700', emoji: '✨' },

function spawnFly() {
  const isGold = Math.random() < Math.min(0.08 + game.difficulty * 0.02, 0.3);
  const t = isGold ? FLY_TYPES.gold : FLY_TYPES.normal;

  const edge = Math.floor(Math.random() * 4);
  let x, y;
  if (edge === 0) { x = Math.random() * W; y = -30; }
  else if (edge === 1) { x = W + 30; y = Math.random() * H; }
  else if (edge === 2) { x = Math.random() * W; y = H + 30; }
  else { x = -30; y = Math.random() * H; }

  const speed = t.speed + game.difficulty * 15;
  const angle = Math.atan2(H / 2 - y, W / 2 - x) + (Math.random() - 0.5) * 1.4;

  game.flies.push({
    x, y,
    vx: Math.cos(angle) * speed,
    vy: Math.sin(angle) * speed,
    radius: t.radius,
    type: isGold ? 'gold' : 'normal',
    score: t.score,
    color: t.color,
    emoji: t.emoji,
    wobblePhase: Math.random() * Math.PI * 2,
    alive: true,
    flashTimer: 0,
    opacity: 1,
  });
}

function updateFlies(dt) {
  for (const f of game.flies) {
    if (!f.alive) continue;
    f.wobblePhase += dt * 8;

    // 金苍蝇随机闪现
    if (f.type === 'gold') {
      f.flashTimer -= dt;
      if (f.flashTimer <= 0) {
        f.flashTimer = 1 + Math.random() * 1.5;
        f.x += (Math.random() - 0.5) * 160;
        f.y += (Math.random() - 0.5) * 160;
        f.opacity = 0.2;
      }
      f.opacity += (1 - f.opacity) * Math.min(dt * 8, 1);
    }

    const wobble = Math.sin(f.wobblePhase) * 30;
    f.x += (f.vx + wobble * 0.3) * dt;
    f.y += (f.vy + Math.cos(f.wobblePhase) * 20) * dt;

    // 出界即移除（不扣命，因为你用打空计数）
    if (f.x < -80 || f.x > W + 80 || f.y < -80 || f.y > H + 80) {
      f.alive = false;
    }
  }
  game.flies = game.flies.filter(f => f.alive);
}

// ============ 粒子 ============
function spawnSplat(x, y, color, count = 14) {
  for (let i = 0; i < count; i++) {
    const a = Math.random() * Math.PI * 2;
    const s = 60 + Math.random() * 200;
    game.particles.push({
      x, y,
      vx: Math.cos(a) * s,
      vy: Math.sin(a) * s,
      life: 0.5 + Math.random() * 0.3,
      maxLife: 0.8,
      color,
      size: 2 + Math.random() * 4,
    });
  }
  if (game.particles.length > 300) {
    game.particles = game.particles.slice(-300);
  }
}

function updateParticles(dt) {
  for (const p of game.particles) {
    p.x += p.vx * dt;
    p.y += p.vy * dt;
    p.vy += 400 * dt;
    p.vx *= 0.98;
    p.life -= dt;
  }
  game.particles = game.particles.filter(p => p.life > 0);
}

  game.texts.push({ text, x, y, life: 1.2, maxLife: 1.2, color, vy: -40 });
}
function updateTexts(dt) {
  for (const t of game.texts) {
    t.y += t.vy * dt;
    t.life -= dt;
  }
  game.texts = game.texts.filter(t => t.life > 0);
}

// ============ 输入 ============
function toCanvasCoord(e) {
  const rect = canvas.getBoundingClientRect();
  return { x: e.clientX - rect.left, y: e.clientY - rect.top };
}

canvas.addEventListener('pointerdown', e => {
  if (game.status !== S.PLAYING) return;
  const { x, y } = toCanvasCoord(e);

  for (let i = game.flies.length - 1; i >= 0; i--) {
    const f = game.flies[i];
    const dx = x - f.x, dy = y - f.y;
    const hitR = f.radius + 10; // 手感放宽
    if (dx * dx + dy * dy <= hitR * hitR) {
      // 命中
      game.score += f.score + game.combo * 2;
      game.hits++;
      game.combo++;
      spawnSplat(f.x, f.y, f.type === 'gold' ? '#ffd700' : '#4a4a4a', f.type === 'gold' ? 24 : 14);
      game.shake = f.type === 'gold' ? 10 : 5;
      game.flies.splice(i, 1);
      return;
    }
  }

  // 打空
  game.missCount++;
  game.combo = 0;
  game.shake = 3;

  // 附近有金苍蝇 → 弹「打不着打不着」
  const goldNear = game.flies.some(f =>
    f.type === 'gold' &&
    (f.x - x) ** 2 + (f.y - y) ** 2 < 150 * 150
  );
  if (goldNear) {
    showText('打不着打不着', x, y - 20, '#ffd700');
  }

  if (game.missCount >= 10) {
    setState(S.FAIL_CRY);
  }
});

function setState(s) {
  game.status = s;
  game.timer = 0;
  onEnter(s);
}

function onEnter(s) {
  if (s === S.TRANSFORM) {
    // 变身白光特效
    spawnSplat(W * 0.75, H * 0.6, '#ffffff', 30);
  }
  if (s === S.BOMB) {
    // 初始化饮料手雷，从人位置飞向屏幕中心
    game.bomb = {
      x: W * 0.15,
      y: H * 0.55,
      startX: W * 0.15,
      startY: H * 0.55,
      targetX: W * 0.5,
      targetY: H * 0.4,
      t: 0,
      duration: 0.9,
      exploded: false,
    };
  }
  if (s === S.CURTAIN) {
    game.curtainY = -1;
  }
  if (s === S.RESULT) {
    const high = Number(localStorage.getItem(HIGH_SCORE_KEY) || 0);
    game.isNewHigh = game.score > high;
    if (game.isNewHigh) {
      localStorage.setItem(HIGH_SCORE_KEY, String(game.score));
    }
    document.getElementById('finalScore').textContent = game.score;
    document.getElementById('highScore').textContent = Math.max(high, game.score);
    document.getElementById('hitCount').textContent = game.hits;
    document.getElementById('missCount').textContent = game.missCount;
    document.getElementById('result').classList.add('show');
  }
}

// ============ 主循环 ============
let last = performance.now();
function loop(now) {
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  game.timer += dt;

  update(dt);
  render();
  requestAnimationFrame(loop);
}

function update(dt) {
  game.shake *= 0.85;

  switch (game.status) {
    case S.IDLE:
      updateFlies(dt);
      if (game.timer > 2.5) setState(S.TRANSFORM);
      break;

    case S.TRANSFORM:
      updateFlies(dt);
      if (game.timer > 1.5) setState(S.PLAYING);
      break;

    case S.PLAYING:
      game.difficulty += dt * 0.08;
      updateFlies(dt);
      game.spawnTimer -= dt;
      const spawnInterval = Math.max(0.35, 1.1 - game.difficulty * 0.05);
      if (game.spawnTimer <= 0 && game.flies.length < 25) {
        spawnFly();
        game.spawnTimer = spawnInterval;
      }
      // 清空所有苍蝇 → 胜利扔炸弹
      if (game.hits > 0 && game.flies.length === 0 && game.timer > 3) {
        setState(S.BOMB);
      }
      break;

    case S.FAIL_CRY:
      updateFlies(dt);
      if (game.timer > 2.5) setState(S.BOMB);
      break;

    case S.BOMB: {
      if (game.bomb) {
        const b = game.bomb;
        b.t += dt;
        const p = Math.min(b.t / b.duration, 1);
        b.x = b.startX + (b.targetX - b.startX) * p;
        // 抛物线
        b.y = b.startY + (b.targetY - b.startY) * p - Math.sin(p * Math.PI) * 180;
        if (p >= 1 && !b.exploded) {
          b.exploded = true;
          // 爆炸清场
          for (const f of game.flies) {
            spawnSplat(f.x, f.y, '#ff8c00', 6);
          }
          game.flies = [];
          spawnSplat(b.targetX, b.targetY, '#ffaa00', 60);
          game.shake = 25;
        }
      }
      updateFlies(dt);
      if (game.timer > 2.5) setState(S.HUG);
      break;
    }

    case S.HUG:
      if (game.timer > 2) setState(S.CURTAIN);
      break;

    case S.CURTAIN:
      game.curtainY += dt * 1.2;
      if (game.timer > 1.4) setState(S.RESULT);
      break;

    case S.RESULT:
      break;
  }

  updateParticles(dt);
  updateTexts(dt);
}

// ============ 渲染 ============
function render() {
  ctx.save();

  // 屏幕震动
  if (game.shake > 0.5) {
    ctx.translate(
      (Math.random() - 0.5) * game.shake,
      (Math.random() - 0.5) * game.shake
    );
  }

  // 背景天空渐变
  const bg = ctx.createLinearGradient(0, 0, 0, H);
  bg.addColorStop(0, '#87CEEB');
  bg.addColorStop(1, '#B0E0E6');
  ctx.fillStyle = bg;
  ctx.fillRect(-50, -50, W + 100, H + 100);

  // 草地
  ctx.fillStyle = '#7CCD7C';
  ctx.fillRect(-50, H * 0.78, W + 100, H * 0.3);

  // 角色
  drawCharacters();

  // 苍蝇
  for (const f of game.flies) {
    ctx.globalAlpha = f.opacity;
    if (hasImg(f.type === 'gold' ? 'goldFly' : 'fly')) {
      const img = images[f.type === 'gold' ? 'goldFly' : 'fly'];
      ctx.drawImage(img, f.x - f.radius, f.y - f.radius, f.radius * 2, f.radius * 2);
    } else {
      ctx.font = `${f.radius * 1.8}px serif`;
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      ctx.fillText(f.emoji, f.x, f.y);
      if (f.type === 'gold') {
        ctx.shadowColor = '#ffd700';
        ctx.shadowBlur = 20;
        ctx.fillText(f.emoji, f.x, f.y);
        ctx.shadowBlur = 0;
      }
    }
    ctx.globalAlpha = 1;
  }

  // 饮料手雷
  if (game.status === S.BOMB && game.bomb) {
    ctx.font = '48px serif';
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillText('🍹', game.bomb.x, game.bomb.y);
  }

  // 粒子
  for (const p of game.particles) {
    ctx.globalAlpha = Math.max(p.life / p.maxLife, 0);
    ctx.fillStyle = p.color;
    ctx.beginPath();
    ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2);
    ctx.fill();
  }
  ctx.globalAlpha = 1;

  // 浮动文字
  for (const t of game.texts) {
    ctx.globalAlpha = Math.min(t.life / t.maxLife, 1);
    ctx.font = 'bold 28px "PingFang SC", "Microsoft YaHei", sans-serif';
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillStyle = 'rgba(0,0,0,.4)';
    ctx.fillText(t.text, t.x + 2, t.y + 2);
    ctx.fillStyle = t.color;
    ctx.fillText(t.text, t.x, t.y);
  }
  ctx.globalAlpha = 1;

  // 幕布
  if (game.status === S.CURTAIN || game.status === S.RESULT) {
    const curtainH = Math.max(0, Math.min(game.curtainY, 1)) * H;
    if (curtainH > 0) {
      const cg = ctx.createLinearGradient(0, 0, 0, curtainH);
      cg.addColorStop(0, '#8B0000');
      cg.addColorStop(1, '#B22222');
      ctx.fillStyle = cg;
      ctx.fillRect(0, 0, W, curtainH);
      // 褶皱
      ctx.strokeStyle = 'rgba(0,0,0,.2)';
      ctx.lineWidth = 2;
      for (let x = 0; x < W; x += 40) {
        ctx.beginPath();
        ctx.moveTo(x, 0);
        ctx.lineTo(x + 20, curtainH);
        ctx.stroke();
      }
    }
  }

  ctx.restore();
}
```

```js
import { FLY_TYPES } from '../constants.js';

export class Fly {
  constructor(W, H, difficulty) {
    const isGold = Math.random() < Math.min(0.08 + difficulty * 0.02, 0.3);
    const t = isGold ? FLY_TYPES.gold : FLY_TYPES.normal;

    const edge = Math.floor(Math.random() * 4);
    let x, y;
    if (edge === 0) { x = Math.random() * W; y = -30; }
    else if (edge === 1) { x = W + 30; y = Math.random() * H; }
    else if (edge === 2) { x = Math.random() * W; y = H + 30; }
    else { x = -30; y = Math.random() * H; }

    const speed = t.speed + difficulty * 15;
    const angle = Math.atan2(H / 2 - y, W / 2 - x) + (Math.random() - 0.5) * 1.4;

    this.x = x;
    this.y = y;
    this.vx = Math.cos(angle) * speed;
    this.vy = Math.sin(angle) * speed;
    this.radius = t.radius;
    this.type = isGold ? 'gold' : 'normal';
    this.score = t.score;
    this.color = t.color;
    this.emoji = t.emoji;
    this.wobblePhase = Math.random() * Math.PI * 2;
    this.alive = true;
    this.flashTimer = 1 + Math.random() * 1.5;
    this.opacity = 1;
  }

  update(dt, W, H) {
    this.wobblePhase += dt * 8;

    if (this.type === 'gold') {
      this.flashTimer -= dt;
      if (this.flashTimer <= 0) {
        this.flashTimer = 1 + Math.random() * 1.5;
        this.x += (Math.random() - 0.5) * 160;
        this.y += (Math.random() - 0.5) * 160;
        this.opacity = 0.2;
      }
      this.opacity += (1 - this.opacity) * Math.min(dt * 8, 1);
    }

    const wobble = Math.sin(this.wobblePhase) * 30;
    this.x += (this.vx + wobble * 0.3) * dt;
    this.y += (this.vy + Math.cos(this.wobblePhase) * 20) * dt;

    if (this.x < -80 || this.x > W + 80 || this.y < -80 || this.y > H + 80) {
      this.alive = false;
    }
  }
}
```

### `src/game/engine/GameEngine.js`
```js
import { S, CONFIG } from './constants.js';
import { Fly } from './entities/Fly.js';

export class GameEngine {
  constructor(canvas, onStateChange) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.onStateChange = onStateChange;
    this.W = 0;
    this.H = 0;
    this.DPR = 1;
    this.images = {};
    this.reset();
    this.resize();
  }

  loadImages(map) {
    for (const [key, src] of Object.entries(map)) {
      const img = new Image();
      img.src = src;
      this.images[key] = img;
    }
  }

  resize() {
    this.DPR = Math.min(window.devicePixelRatio || 1, 2);
    this.W = window.innerWidth;
    this.H = window.innerHeight;
    this.canvas.width = this.W * this.DPR;
    this.canvas.height = this.H * this.DPR;
    this.ctx.setTransform(this.DPR, 0, 0, this.DPR, 0, 0);
  }

  reset() {
    this.status = S.IDLE;
    this.timer = 0;
    this.score = 0;
    this.hits = 0;
    this.missCount = 0;
    this.combo = 0;
    this.difficulty = 0;
    this.flies = [];
    this.particles = [];
    this.texts = [];
    this.spawnTimer = 0;
    this.shake = 0;
    this.curtainY = -1;
    this.bomb = null;
    this.onStateChange?.({ status: this.status, score: 0, missCount: 0 });
  }

  setState(s) {
    this.status = s;
    this.timer = 0;
    if (s === S.BOMB) {
      this.bomb = {
        x: this.W * 0.15, y: this.H * 0.55,
        startX: this.W * 0.15, startY: this.H * 0.55,
        targetX: this.W * 0.5, targetY: this.H * 0.4,
        t: 0, duration: 0.9, exploded: false,
      };
    }
    if (s === S.CURTAIN) this.curtainY = -1;
    if (s === S.RESULT) {
      const high = Number(localStorage.getItem(CONFIG.HIGH_SCORE_KEY) || 0);
      if (this.score > high) {
        localStorage.setItem(CONFIG.HIGH_SCORE_KEY, String(this.score));
      }
    }
    this.onStateChange?.({
      status: this.status,
      score: this.score,
      missCount: this.missCount,
      hits: this.hits,
    });
  }

  handlePointerDown(px, py) {
    if (this.status !== S.PLAYING) return;

    for (let i = this.flies.length - 1; i >= 0; i--) {
      const f = this.flies[i];
      const dx = px - f.x, dy = py - f.y;
      const hitR = f.radius + 10;
      if (dx * dx + dy * dy <= hitR * hitR) {
        this.score += f.score + this.combo * 2;
        this.hits++;
        this.combo++;
        this.spawnSplat(f.x, f.y, f.type === 'gold' ? '#ffd700' : '#4a4a4a', f.type === 'gold' ? 24 : 14);
        this.shake = f.type === 'gold' ? 10 : 5;
        this.flies.splice(i, 1);
        this.onStateChange?.({ status: this.status, score: this.score, missCount: this.missCount, hits: this.hits });
        return;
      }
    }

    this.missCount++;
    this.combo = 0;
    this.shake = 3;

    const goldNear = this.flies.some(f =>
      f.type === 'gold' && (f.x - px) ** 2 + (f.y - py) ** 2 < 150 * 150
    );
    if (goldNear) this.showText('打不着打不着', px, py - 20, '#ffd700');

    this.onStateChange?.({ status: this.status, score: this.score, missCount: this.missCount, hits: this.hits });

    if (this.missCount >= CONFIG.MAX_MISS) this.setState(S.FAIL_CRY);
  }

  spawnSplat(x, y, color, count = 14) {
    for (let i = 0; i < count; i++) {
      const a = Math.random() * Math.PI * 2;
      const s = 60 + Math.random() * 200;
      this.particles.push({
        x, y,
        vx: Math.cos(a) * s, vy: Math.sin(a) * s,
        life: 0.5 + Math.random() * 0.3, maxLife: 0.8,
        color, size: 2 + Math.random() * 4,
      });
    }
    if (this.particles.length > CONFIG.MAX_PARTICLES) {
      this.particles = this.particles.slice(-CONFIG.MAX_PARTICLES);
    }
  }

  showText(text, x, y, color) {
    this.texts.push({ text, x, y, life: 1.2, maxLife: 1.2, color, vy: -40 });
  }

  update(dt) {
    this.timer += dt;
    this.shake *= 0.85;

    switch (this.status) {
      case S.IDLE:
        this.updateFlies(dt);
        if (this.timer > 2.5) this.setState(S.TRANSFORM);
        break;
      case S.TRANSFORM:
        this.updateFlies(dt);
        if (this.timer > 1.5) this.setState(S.PLAYING);
        break;
      case S.PLAYING: {
        this.difficulty += dt * 0.08;
        this.updateFlies(dt);
        this.spawnTimer -= dt;
        const interval = Math.max(0.35, 1.1 - this.difficulty * 0.05);
        if (this.spawnTimer <= 0 && this.flies.length < CONFIG.MAX_FLIES) {
          this.flies.push(new Fly(this.W, this.H, this.difficulty));
          this.spawnTimer = interval;
        }
        if (this.hits > 0 && this.flies.length === 0 && this.timer > 3) {
          this.setState(S.BOMB);
        }
        break;
      }
      case S.FAIL_CRY:
        this.updateFlies(dt);
        if (this.timer > 2.5) this.setState(S.BOMB);
        break;
      case S.BOMB: {
        if (this.bomb) {
          const b = this.bomb;
          b.t += dt;
          const p = Math.min(b.t / b.duration, 1);
          b.x = b.startX + (b.targetX - b.startX) * p;
          b.y = b.startY + (b.targetY - b.startY) * p - Math.sin(p * Math.PI) * 180;
          if (p >= 1 && !b.exploded) {
            b.exploded = true;
            for (const f of this.flies) this.spawnSplat(f.x, f.y, '#ff8c00', 6);
            this.flies = [];
            this.spawnSplat(b.targetX, b.targetY, '#ffaa00', 60);
            this.shake = 25;
          }
        }
        this.updateFlies(dt);
        if (this.timer > 2.5) this.setState(S.HUG);
        break;
      }
      case S.HUG:
        if (this.timer > 2) this.setState(S.CURTAIN);
        break;
      case S.CURTAIN:
        this.curtainY += dt * 1.2;
        if (this.timer > 1.4) this.setState(S.RESULT);
        break;
      case S.RESULT:
        break;
    }

    for (const p of this.particles) {
      p.x += p.vx * dt; p.y += p.vy * dt;
      p.vy += 400 * dt; p.vx *= 0.98; p.life -= dt;
    }
    this.particles = this.particles.filter(p => p.life > 0);

    for (const t of this.texts) {
      t.y += t.vy * dt;
      t.life -= dt;
    }
    this.texts = this.texts.filter(t => t.life > 0);
  }

  updateFlies(dt) {
    for (const f of this.flies) f.update(dt, this.W, this.H);
    this.flies = this.flies.filter(f => f.alive);
  }

  render() {
    const ctx = this.ctx;
    ctx.save();

    if (this.shake > 0.5) {
      ctx.translate(
        (Math.random() - 0.5) * this.shake,
        (Math.random() - 0.5) * this.shake
      );
    }

    // 背景
    const bg = ctx.createLinearGradient(0, 0, 0, this.H);
    bg.addColorStop(0, '#87CEEB');
    bg.addColorStop(1, '#B0E0E6');
    ctx.fillStyle = bg;
    ctx.fillRect(-50, -50, this.W + 100, this.H + 100);

    ctx.fillStyle = '#7CCD7C';
    ctx.fillRect(-50, this.H * 0.78, this.W + 100, this.H * 0.3);

    this.drawCharacters();

    // 苍蝇
    for (const f of this.flies) {
      ctx.globalAlpha = f.opacity;
      ctx.font = `${f.radius * 1.8}px serif`;
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      ctx.fillText(f.emoji, f.x, f.y);
      ctx.globalAlpha = 1;
    }

    // 手雷
    if (this.status === S.BOMB && this.bomb) {
      ctx.font = '48px serif';
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      ctx.fillText('🍹', this.bomb.x, this.bomb.y);
    }

    // 粒子
    for (const p of this.particles) {
      ctx.globalAlpha = Math.max(p.life / p.maxLife, 0);
      ctx.fillStyle = p.color;
      ctx.beginPath();
      ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2);
      ctx.fill();
    }
    ctx.globalAlpha = 1;

    // 浮动文字
    for (const t of this.texts) {
      ctx.globalAlpha = Math.min(t.life / t.maxLife, 1);
      ctx.font = 'bold 28px "PingFang SC", sans-serif';
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      ctx.fillStyle = 'rgba(0,0,0,.4)';
      ctx.fillText(t.text, t.x + 2, t.y + 2);
      ctx.fillStyle = t.color;
      ctx.fillText(t.text, t.x, t.y);
    }
    ctx.globalAlpha = 1;

    // 幕布
    if (this.status === S.CURTAIN || this.status === S.RESULT) {
      const curtainH = Math.max(0, Math.min(this.curtainY, 1)) * this.H;
      if (curtainH > 0) {
        const cg = ctx.createLinearGradient(0, 0, 0, curtainH);
        cg.addColorStop(0, '#8B0000');
        cg.addColorStop(1, '#B22222');
        ctx.fillStyle = cg;
        ctx.fillRect(0, 0, this.W, curtainH);
      }
    }

    ctx.restore();
  }

  drawCharacters() {
    const ctx = this.ctx;
    const groundY = this.H * 0.82;
    const scale = Math.min(this.W, this.H) / 800;

    // 人
    const manX = this.W * 0.15;
    ctx.font = `${140 * scale}px serif`;
    ctx.textAlign = 'center';
    ctx.textBaseline = 'bottom';
    ctx.fillText('🧑', manX, groundY);

    if (this.status === S.IDLE) {
      ctx.font = `${32 * scale}px serif`;
      ctx.fillText('😤', manX + 60 * scale, groundY - 140 * scale);
    }

    // 兔子
    if (this.status === S.IDLE || this.status === S.TRANSFORM) {
      const rabbitX = this.W * 0.78;
      if (this.status === S.TRANSFORM) {
        const p = this.timer / 1.5;
        ctx.globalAlpha = 1 - p;
        ctx.fillStyle = '#fff';
        ctx.beginPath();
        ctx.arc(rabbitX, groundY - 60 * scale, 80 * scale * (1 + p), 0, Math.PI * 2);
        ctx.fill();
        ctx.globalAlpha = 1;
      }
      ctx.font = `${140 * scale}px serif`;
      ctx.fillText('🐰', rabbitX, groundY);
    }

    // 兔子小孩
    if ([S.PLAYING, S.FAIL_CRY, S.BOMB, S.HUG].includes(this.status)) {
      const kidX = this.W * 0.6;
      if (this.status === S.FAIL_CRY) {
        ctx.font = `${110 * scale}px serif`;
        ctx.fillText('😭', kidX, groundY);
      } else if (this.status === S.HUG) {
        const p = Math.min(this.timer / 1.5, 1);
        ctx.font = `${110 * scale}px serif`;
        ctx.fillText('🥰', kidX, groundY - 100 * scale * p);
      } else {
        ctx.font = `${120 * scale}px serif`;
        ctx.fillText('🧒', kidX, groundY);
        ctx.font = `${60 * scale}px serif`;
        ctx.fillText('🏸', kidX + 50 * scale, groundY - 60 * scale);
      }
    }
  }
}
```

### `src/game/hooks/useGameEngine.js`
```js
import { useEffect, useRef, useState } from 'react';
import { GameEngine } from '../engine/GameEngine.js';

export function useGameEngine(canvasRef) {
  const engineRef = useRef(null);
  const [hud, setHud] = useState({ status: 'idle', score: 0, missCount: 0, hits: 0 });

  useEffect(() => {
    if (!canvasRef.current) return;
    const engine = new GameEngine(canvasRef.current, setHud);
    engineRef.current = engine;

    const onResize = () => engine.resize();
    window.addEventListener('resize', onResize);

    const onPointerDown = (e) => {
      const rect = canvasRef.current.getBoundingClientRect();
      engine.handlePointerDown(e.clientX - rect.left, e.clientY - rect.top);
    };
    canvasRef.current.addEventListener('pointerdown', onPointerDown);

    let raf;
    let last = performance.now();
    const loop = (now) => {
      const dt = Math.min((now - last) / 1000, 0.05);
      last = now;
      engine.update(dt);
      engine.render();
      raf = requestAnimationFrame(loop);
    };
    raf = requestAnimationFrame(loop);

    return () => {
      cancelAnimationFrame(raf);
      window.removeEventListener('resize', onResize);
      canvasRef.current?.removeEventListener('pointerdown', onPointerDown);
    };
  }, [canvasRef]);

  return { engine: engineRef.current, hud };
}
```

# 一、素材加载器 `AssetLoader.js`

支持图片、音频、进度回调、失败兜底。

```js
// engine/AssetLoader.js
export class AssetLoader {
  constructor() {
    this.images = {};
    this.audios = {};
    this.total = 0;
    this.loaded = 0;
    this.failed = [];
  }

  /**
   * @param {Object} imageMap  { key: 'url' }
   * @param {Object} audioMap  { key: 'url' }
   * @param {(progress:number)=>void} onProgress  0~1
   */
  async load(imageMap = {}, audioMap = {}, onProgress) {
    const imageEntries = Object.entries(imageMap);
    const audioEntries = Object.entries(audioMap);
    this.total = imageEntries.length + audioEntries.length;
    this.loaded = 0;

    const tasks = [
      ...imageEntries.map(([key, src]) => this._loadImage(key, src, onProgress)),
      ...audioEntries.map(([key, src]) => this._loadAudio(key, src, onProgress)),
    ];

    await Promise.all(tasks);
    return { images: this.images, audios: this.audios, failed: this.failed };
  }

  _loadImage(key, src, onProgress) {
    return new Promise((resolve) => {
      const img = new Image();
      img.onload = () => {
        this.images[key] = img;
        this._tick(onProgress);
        resolve();
      };
      img.onerror = () => {
        this.failed.push({ type: 'image', key, src });
        this._tick(onProgress);
        resolve();
      };
      img.src = src;
    });
  }

  _loadAudio(key, src, onProgress) {
    return new Promise((resolve) => {
      const audio = new Audio();
      audio.preload = 'auto';
      audio.src = src;
      const done = () => {
        this.audios[key] = audio;
        this._tick(onProgress);
        resolve();
      };
      audio.oncanplaythrough = done;
      audio.onerror = () => {
        this.failed.push({ type: 'audio', key, src });
        this._tick(onProgress);
        resolve();
      };
      // 兜底：3 秒还没 loaded 也放行，避免卡死
      setTimeout(done, 3000);
    });
  }

  _tick(onProgress) {
    this.loaded++;
    onProgress?.(this.loaded / this.total);
  }

  hasImage(key) {
    const img = this.images[key];
    return img && img.complete && img.naturalWidth > 0;
  }

  getImage(key) {
    return this.images[key];
  }
}
```

# 二、精灵动画系统 `Sprite.js`

支持**单帧图**和**横向序列帧 sprite sheet**，按时间切帧。

```js
// engine/Sprite.js
export class Sprite {
  /**
   * @param {HTMLImageElement} image
   * @param {Object} opts
   *   frameCount  帧数，默认 1（单帧图）
   *   fps         播放速度
   *   loop        是否循环
   *   width/height 单帧显示尺寸（不传则用图片原始宽/帧数）
   */
  constructor(image, opts = {}) {
    this.image = image;
    this.frameCount = opts.frameCount || 1;
    this.fps = opts.fps || 8;
    this.loop = opts.loop !== false;
    this.displayW = opts.width || 0;
    this.displayH = opts.height || 0;

    this.frame = 0;
    this.time = 0;
    this.finished = false;
  }

  reset() {
    this.frame = 0;
    this.time = 0;
    this.finished = false;
  }

  update(dt) {
    if (this.finished) return;
    this.time += dt;
    const frameDuration = 1 / this.fps;
    while (this.time >= frameDuration) {
      this.time -= frameDuration;
      this.frame++;
      if (this.frame >= this.frameCount) {
        if (this.loop) {
          this.frame = 0;
        } else {
          this.frame = this.frameCount - 1;
          this.finished = true;
          break;
        }
      }
    }
  }

  /**
   * @param {CanvasRenderingContext2D} ctx
   * @param {number} x  底部中心 x
   * @param {number} y  底部中心 y
   * @param {number} scale
   * @param {boolean} flipX
   */
  draw(ctx, x, y, scale = 1, flipX = false) {
    if (!this.image || !this.image.complete || !this.image.naturalWidth) return;

    const frameW = this.image.naturalWidth / this.frameCount;
    const frameH = this.image.naturalHeight;

    const w = (this.displayW || frameW) * scale;
    const h = (this.displayH || frameH) * scale;

    ctx.save();
    ctx.translate(x, y);
    if (flipX) ctx.scale(-1, 1);
    ctx.drawImage(
      this.image,
      this.frame * frameW, 0, frameW, frameH,
      -w / 2, -h, w, h
    );
    ctx.restore();
  }
}
```

### 动画管理器 `AnimationBank.js`

```js
// engine/AnimationBank.js
import { Sprite } from './Sprite.js';

export class AnimationBank {
  constructor() {
    this.bank = {}; // { man: { idle: Sprite, annoyed: Sprite }, ... }
  }

  /**
   * @param {string} actor   角色名，如 'man'
   * @param {string} action  动作名，如 'idle'
   * @param {HTMLImageElement} image
   * @param {Object} opts    { frameCount, fps, loop, width, height }
   */
  register(actor, action, image, opts) {
    if (!this.bank[actor]) this.bank[actor] = {};
    this.bank[actor][action] = new Sprite(image, opts);
  }

  get(actor, action) {
    return this.bank[actor]?.[action] || null;
  }

  update(dt) {
    for (const actor of Object.values(this.bank)) {
      for (const sprite of Object.values(actor)) {
        sprite.update(dt);
      }
    }
  }

  play(actor, action) {
    const s = this.get(actor, action);
    if (s) s.reset();
    return s;
  }
}
```

# 三、音效管理器 `AudioManager.js`

支持池化、音量、静音、BGM 循环、浏览器自动播放策略解锁。

```js
// engine/AudioManager.js
export class AudioManager {
  constructor() {
    this.audios = {};       // { key: HTMLAudioElement }  原始模板
    this.pools = {};        // { key: HTMLAudioElement[] } 池
    this.poolIndex = {};    // { key: number }
    this.poolSize = 4;      // 每个音效同时最多 4 个
    this.masterVolume = 1;
    this.sfxVolume = 1;
    this.bgmVolume = 0.5;
    this.muted = false;
    this.currentBgm = null;
    this.unlocked = false;
  }

  init(audios) {
    this.audios = audios || {};
    for (const key of Object.keys(this.audios)) {
      this.pools[key] = [];
      this.poolIndex[key] = 0;
    }
  }

  /** 浏览器要求用户交互后才能播放音频 */
  unlock() {
    if (this.unlocked) return;
    this.unlocked = true;
    // 播一个静音的空音频解锁
    try {
      const ctx = new (window.AudioContext || window.webkitAudioContext)();
      ctx.resume();
    } catch (e) { /* ignore */ }
  }

  setMuted(m) {
    this.muted = m;
    if (this.currentBgm) {
      this.currentBgm.muted = m;
    }
  }

  /** 播放音效（池化，重叠播放） */
  play(key, volume = 1) {
    if (this.muted) return;
    const template = this.audios[key];
    if (!template) return;

    let pool = this.pools[key];
    if (!pool || pool.length === 0) {
      // 首次播放，创建池
      pool = [];
      for (let i = 0; i < this.poolSize; i++) {
        const a = template.cloneNode();
        a.volume = 0;
        pool.push(a);
      }
      this.pools[key] = pool;
      this.poolIndex[key] = 0;
    }

    const idx = this.poolIndex[key];
    const audio = pool[idx];
    this.poolIndex[key] = (idx + 1) % this.poolSize;

    audio.currentTime = 0;
    audio.volume = Math.min(this.masterVolume * this.sfxVolume * volume, 1);
    audio.play().catch(() => { /* 自动播放被拦截，忽略 */ });
  }

  /** 播放 BGM（循环，单实例） */
  playBgm(key, volume = 1) {
    this.stopBgm();
    const template = this.audios[key];
    if (!template) return;

    const bgm = template.cloneNode();
    bgm.loop = true;
    bgm.volume = Math.min(this.masterVolume * this.bgmVolume * volume, 1);
    bgm.muted = this.muted;
    bgm.play().catch(() => { /* ignore */ });
    this.currentBgm = bgm;
  }

  stopBgm() {
    if (this.currentBgm) {
      this.currentBgm.pause();
      this.currentBgm.currentTime = 0;
      this.currentBgm = null;
    }
  }

  fadeBgm(targetVolume, duration = 1) {
    if (!this.currentBgm) return;
    const start = this.currentBgm.volume;
    const startTime = performance.now();
    const tick = () => {
      const p = Math.min((performance.now() - startTime) / (duration * 1000), 1);
      this.currentBgm.volume = start + (targetVolume - start) * p;
      if (p < 1) requestAnimationFrame(tick);
    };
    tick();
  }
}
```
